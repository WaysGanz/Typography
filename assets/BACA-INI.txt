Taruh foto kamu di folder ini (jpg/png/webp), lalu tulis nama filenya di content.js.
Nama file bebas, asal sama persis (huruf kecil, tanpa spasi lebih aman).
Contoh bawaan: merbabu-1, cikuray-1, ciremai-1, papandayan-1,
touring-1..3, dump-1..5 (.jpg). Belum ada file = tampil gradient gunung.
Tips: kecilkan foto ke lebar sekitar 1600px biar cepat dibuka.
